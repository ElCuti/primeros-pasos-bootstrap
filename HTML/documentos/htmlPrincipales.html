Etiqueta Descripción Enlace
<p></p> El elemento p (párrafo) es el apropiado para distribuir el texto en párrafos.
<div></div> Sirve para crear secciones o agrupar contenidos
<span></span> Es un contenedor en línea. Sirve para aplicar estilo al texto o agrupar elementos en línea
<img></img> El elemento de imagen HTML representa una imagen en el documento
<ul><li> Crea una lista no ordenada
<ol><li> El elemento ol permite definir listas o viñetas ordenadas ("Ordered List"), bien con numeración o alfabéticamente
<a></a> Crea un enlace a otras páginas de internet, archivos o ubicaciones dentro de la misma página, direcciones de correo, o cualquier otra URL.
