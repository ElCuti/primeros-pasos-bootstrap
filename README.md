# 🚀 Iniciación a Bootstrap

¡Bienvenido a mi primer proyecto utilizando **Bootstrap**! 

Este repositorio es un reflejo de mi proceso de aprendizaje con este framework. A lo largo de **35 commits**, he ido construyendo y documentando diversos ejercicios prácticos conforme aprendía a utilizar las distintas herramientas, componentes y el sistema de cuadrículas (Grid) que ofrece Bootstrap.

## 📂 ¿Qué vas a encontrar aquí?

El proyecto está compuesto por varios ejercicios divididos en distintas carpetas, donde fui aplicando de forma progresiva lo que iba aprendiendo

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica de las páginas.
*   **CSS3:** Estilos personalizados para complementar el framework.
*   **Bootstrap:** Framework principal utilizado para el diseño responsivo, sistema de grid, utilidades y componentes visuales.

## 🎯 Objetivo del Proyecto

El objetivo principal de este repositorio fue aprender a hacer uso de un framework de CSS para entender las facilidades que estos atribuían al desarrollo web.
